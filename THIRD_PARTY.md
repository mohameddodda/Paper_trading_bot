# Third-Party API and Data Source Compliance

This document outlines the third-party APIs and data sources used by the Paper Trading Bot and the compliance requirements for users.

---

## Overview

The Paper Trading Bot utilizes various third-party APIs and data sources to provide market data, AI signals, and other functionality. Users of this software must comply with the terms of service, usage policies, and any attribution requirements of these external providers.

---

## User Responsibilities

### Compliance with Terms of Service

Users are **solely responsible** for:

1. **Reading and understanding** the terms of service of all third-party APIs and data providers
2. **Complying with** all applicable terms of service, usage policies, and rate limits
3. **Obtaining any necessary permissions** or licenses required by third-party providers
4. **Monitoring** for changes to third-party terms and adapting usage accordingly

### API Key Management

- Users must obtain their own API keys for services that require authentication
- Users are responsible for securing and protecting their API keys
- Users must not share their API keys in public repositories or with unauthorized parties
- Users should regularly rotate API keys as recommended by providers

### Rate Limits and Usage

- Users must respect the rate limits imposed by third-party providers
- Excessive usage may result in API access being revoked or throttled
- Users should implement appropriate caching and request throttling

### Attribution Requirements

Some third-party services may require attribution. Users should:

- Review the attribution requirements of each provider
- Include required attributions in any derivative works or distributions
- Consult the provider's documentation for specific attribution requirements
